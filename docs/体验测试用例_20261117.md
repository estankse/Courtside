# 羽序体验测试用例（2026年11月17日）

## 一、版本和准备

本轮将裁判端摄影启动页改为首帧绘制后停留约3.5秒，支持轻触跳过；沿用已选定的蓝绿立体徽章。以下是可执行的人工体验用例，准备数据成功不代表各项人工操作已经全部通过。

当前开发服务为电脑本机8080端口。模拟器使用 `http://10.0.2.2:8080/api`；使用ADB端口转发时可用 `http://127.0.0.1:8080/api`。真机需填写电脑局域网地址并保持网络可达。

表1-1 测试账号

| 角色 | 账号 | 开发演示密码 | 用途 |
| --- | --- | --- | --- |
| 裁判 | referee | Courtside2026! | 所有新增比赛均分配给该账号 |
| 赛事组 | organizer | Courtside2026! | 发布草稿、核验与退回成绩；密码需手动输入 |

安装新版 `dist/courtside-referee.apk` 后冷启动。进入裁判端“我的赛程”，点击刷新，查看2026年11月17日的比赛。只返回桌面再切回来通常是恢复页面，不会重新播放启动页；要重复体验请从最近任务关闭再打开。

## 三、操作用例

表3-1 操作测试用例

| 编号 | 用例 | 步骤 | 预期结果 |
| --- | --- | --- | --- |
| TC-01 | 摄影启动页停留 | 关闭裁判端任务后重新打开，不触碰屏幕；再试一次启动时旋转屏幕 | 照片实际呈现后停留约3.5秒，再淡出进入应用；不会加载后立即闪过；旋转保持同一照片并继续原计时 |
| TC-02 | 跳过和恢复 | 冷启动后轻触“轻触进入”；进入后返回桌面再切回 | 点击后进入应用，无需等满3.5秒；切回已打开的页面不重播启动页 |
| TC-03 | 任务接受和赛程调整 | 打开体验04并接受；在赛事组调整该场尚未开始的时间，再在裁判端刷新 | 原先为待接受，接受后可赛前准备；调整后重新待接受，显示最新安排；开始后不允许继续调整安排 |
| TC-04 | 赛前与入场 | 打开已接受的体验02，进入赛前准备，完成抽签与初始发球设置，确认开始；横竖屏分别观察 | 对阵姓名、双方、规则和发球设置正确；播放对阵入场动画；可跳过；进入记分后比分初始为0:0 |
| TC-05 | 标准计分与休息 | 用体验01接受并开始，给双方加分，撤销一分，交换显示，切换明暗和横竖屏；继续至中场及局末，确认本局 | 分数、发球方与发球区正确；横屏触控区域便于操作；休息界面显示对应主题；提前结束休息可返回；轮转或重开不重置实际结束时刻 |
| TC-06 | 离线保存与续赛 | 用体验03在线开始，记几分后暂时断开测试设备网络，再计分并保存返回；在原设备重开，再恢复网络 | 计分先保存本机，断网不阻塞加分；同账号同设备能继续原场；联网后恢复同步；不要卸载或清除数据 |
| TC-07 | 快速完赛与核验 | 用体验05开赛，蓝方计到5:0，处理出现的间歇，确认本局和双方现场确认后提交；赛事组选择快速流程体验赛，在成绩中核验 | 一局即完赛；裁判端收到云端回执后显示待核验；赛事组确认后成为正式完成；待核验阶段由赛事组操作 |
| TC-08 | 退回与更正 | 用体验06完成一局并提交；赛事组填写原因退回；原裁判在原设备刷新、进入更正，将比分改为合法比分并填写原因，再让双方确认、重新提交，最后由赛事组确认 | 显示退回原因，更正批次增加；原始提交和逐分记录保留；再次提交需双方确认；正式结果以最新核验为准 |
| TC-09 | 弃权处理 | 用体验07开始后选择弃权，指定获胜方并填写原因；确认并提交，再由赛事组核验 | 显示独立弃权结果和原因，不伪造正常完赛局分；赛事组能查看并核验 |
| TC-10 | 草稿发布 | 赛事组选择快速流程体验赛，检查体验08的双方、时间、场地和裁判，发布；裁判端刷新 | 发布前裁判端不显示该场；发布后出现待接受任务，可继续抽签与计分 |

同一场正式开始后不支持换机继续，所以不提前通过脚本伪造进行中、待核验或已退回的比赛。这些状态由上述用例在用户实际设备上自然生成。

## 四、再次准备新一轮

已有场次可以继续使用。以下命令通过正常业务接口检查或补齐本批次；重复执行不会删除比赛或清空比分，也不会把已开赛的比赛重置为未开赛。

```powershell
./scripts/prepare-test-matches.ps1 -Date 2026-11-17 -Batch 20261117
```

想重新体验一整套未开赛比赛，换一个批次即可，例如：

```powershell
./scripts/prepare-test-matches.ps1 -Date 2026-11-17 -Batch 20261117-B
```

本次比赛编号清单位于项目同级 `tmp/referee-experience-20261117/matches.json`，不包含登录令牌。默认脚本清单位置为同级 `tmp/test-matches-批次号`。当前原有邀请赛、历史比赛与本机计分记录均保留。
